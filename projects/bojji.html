Why it exists

01

The good note and task tools charge for sync or cap their free plans: Evernote, Obsidian Sync, Todoist. Syncing a few kilobytes of text between your own devices should not need a subscription, and the text should not live in someone else’s database to begin with.

Bojji runs no storage servers. It reads and writes your notes and tasks directly through the GitHub API, in a repository you already own. If Bojji disappeared tomorrow, the files would still be there, in Markdown, with their full history.

How it works

02

  1. Your repository

    Notes and tasks are kept in a private repository in your GitHub account. No Bojji server holds a copy.

  2. Plain Markdown

    Each note and each task is a Markdown file. Open it on GitHub or in any editor and it reads the same.

  3. Every save a commit

    Changes are versioned as you go. The sync status shows each one as “Kept in your GitHub”.

  4. No silent overwrites

    If the same item changed somewhere else, Bojji detects the conflict instead of writing over it.

Notes and tasks, together

03

Tasks and notes sit side by side and share the same tags, so a project’s to-dos and its meeting notes are one click apart.

  • Tasks with due dates, in Today, a Week schedule that runs Monday to Sunday including the days already past, All tasks and Completed.
  • Markdown notes, rendered in place as you read them.
  • Tags on tasks and notes, in matte colours. Click one to see everything that has it.
  • Light and dark mode, and a layout that works at phone width.

On a phone the three panes become one, with a back button to the lists. Same data, same repository.

Native mobile apps are planned for later. Today it is the web app at phone width.

Where it stands

04

Bojji runs locally today, with Node 22 and your GitHub CLI login. “Sign in with GitHub” for everyone is not built yet.
