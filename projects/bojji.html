Why it exists

01

Evernote, Obsidian Sync and Todoist charge for sync or cap their free plans. Syncing a few kilobytes of your own text should not need a subscription, or live in someone else’s database.

Bojji runs no storage servers. It talks straight to the GitHub API, in a repository you own. If Bojji disappeared tomorrow, your files would still be there, with their full history.

How it works

02

  1. Your repository

    A private repository in your GitHub account. No Bojji server holds a copy.

  2. Plain Markdown

    One Markdown file per note or task. It reads the same on GitHub or in any editor.

  3. Every save a commit

    Changes are versioned as you go.

  4. No silent overwrites

    If an item changed on another device, Bojji catches the conflict instead of writing over it.

Notes and tasks, together

03

Tasks and notes share the same tags, so a project’s to-dos and its meeting notes are one click apart.

  • Tasks with due dates, in Today, Week, All and Completed.
  • Markdown notes, rendered in place.
  • Colour tags. Click one to see everything that has it.
  • Light and dark mode, and works at phone width.

On a phone the three panes become one. Same data, same repository.
